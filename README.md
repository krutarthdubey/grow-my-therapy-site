# Dr. Maya Reynolds Therapy Website

A responsive Next.js and Tailwind CSS homepage redesign for the Grow My Therapy practical assignment. The section order follows the Conejo Valley Counseling reference homepage, with Maya's supplied profile, a dedicated office gallery, and profile-grounded FAQs.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To create and run the production build:

```bash
npm run build
npm start
```

## Deploy

Push this folder to a Git provider and import it into Vercel, or use another Node.js host that supports Next.js. The default build command is `npm run build`; the production start command is `npm start`. No environment variables are required.
